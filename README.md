## План

| Действие                                                          | Описание                                                                                                                                                | 
|-------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------| 
| 1) `/sign-in или /sign-in-without-sms`                            | 1. Идентификация<br/> 2. Поместить код 1 фактора в бд.<br/> 3. Отправить sms с кодом 1 фактора на телефон(либо не отправлять если /sign-in-without-sms). |
| 2) `/verify-code`                                                 | 1. Сверить пересланый код 1 фактора с бд.<br/> 2. Сохранить код 2 фактора в бд.                                                                         |
| 3) `/send-push-for-debug или vpn client или cmd/radius_client.go` | 1. Отправить push.<br/>2. Если тестриуете через /send-push-for-debug, то он будет дожидаться вашего ответа на push и после вернет результат             |
| 4) `/push-answer`                                                 | 1. Отправить ответ на push в систему. Можно воспользоватья ui/mobile для геренирования FCM строки.                                                      |

# Конфигурация окружения

## Rest server

| Переменная              | Тип    | Описание                                                 |
| ----------------------- | ------ | -------------------------------------------------------- |
| `APP_PORT`              | string | Порт, на котором запускается сервис (например, `"8080"`) |
| `LOG_LEVEL`             | int    | Уровень логирования (см. [Логирование](#-логирование))   |
| `SHUTDOWN_PERIOD`       | int    | Время на мягкое завершение (в секундах)                  |
| `SHUTDOWN_HARD_PERIOD`  | int    | Время до принудительного завершения (в секундах)         |
| `READINESS_DRAIN_DELAY` | int    | Задержка перед сигналом `readiness` (в секундах)         |
| `PUSH_SESSION_TTL_IN_MINUTES`                  | string | Время жизни ответа на push |

## Radius server

| Переменная              | Тип    | Описание                                                 |
| ----------------------- | ------ | -------------------------------------------------------- |
| `RADIUS_SECRET`              | string | Аутентификатор |

## Rocket SMS

| Переменная                          | Тип    | Описание                                        |
|-------------------------------------| ------ |-------------------------------------------------|

## Логирование

Используется переменная LOG_LEVEL, соответствующая уровням логирования log/slog:

| Значение | Уровень         | Описание              |
|----------| --------------- | --------------------- |
| `-4`     | `LevelDebug`    | Отладочные сообщения  |
| `0`      | `LevelInfo`     | Информационные логи   |
| `4`      | `LevelWarn`     | Предупреждения        |
| `8`      | `LevelError`    | Ошибки                |
